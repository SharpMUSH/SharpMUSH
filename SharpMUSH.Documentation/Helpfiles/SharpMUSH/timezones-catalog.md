# Historical Timezone Catalog

This is a list of IANA time zones names as of version 2011n of their database. See http://www.iana.org/time-zones for more information and sources.

This catalog is a preserved historical snapshot, not the server's current list. Use `valid(timezone,<tz>)` to check a name against the installed timezone data. The current IANA database is available at https://www.iana.org/time-zones.

- [timezones pacific]: zones under Pacific/
