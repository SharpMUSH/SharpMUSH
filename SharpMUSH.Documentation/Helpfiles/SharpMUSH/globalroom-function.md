# globalroom()

`globalroom()`

globalroom() returns the master room, the room whose exits and commands work everywhere, to a wizard or royalty. Anyone else gets `#-1 PERMISSION DENIED`.

globalroom() comes from RhostMUSH.

```sharp
> think globalroom()
#2
```
