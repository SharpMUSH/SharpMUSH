# @eval

`@eval <expression>`

@eval evaluates `<expression>` and shows nothing. It runs functions for what they do, as think does without the output.

@eval comes from RhostMUSH.

```sharp
> @eval [pemit(me, Hello)]
Hello
> @eval [add(1, 2)]
```

- [think]
:::
