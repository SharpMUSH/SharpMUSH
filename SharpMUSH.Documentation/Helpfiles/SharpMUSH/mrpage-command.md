# mrpage

`mrpage <message>`

mrpage replies to everyone in the last page you received: the player who sent it and everyone else it reached. The whole argument is the message. `/noansi` is accepted and changes nothing.

mrpage comes from RhostMUSH. page/reply answers only the sender.

```sharp
Alice pages: Lunch?  (to Bob and you)
> mrpage Yes
You paged Alice and Bob with 'Yes'.
```
