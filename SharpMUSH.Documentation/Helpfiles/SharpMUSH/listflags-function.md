# listflags()

`listflags()`

listflags() returns every flag you may see, sorted by name, each written as its name and its letter in parentheses. Disabled flags are left out; a dark flag is listed only to God, and an mdark one only to those who may see all.

listflags() comes from RhostMUSH. lflags() with no argument lists the names alone.

```sharp
> think first(listflags())
ABODE(A)
```
