Versioned, additive
Every payload carries "v": 2. Today's parser reads only dbref, name and cmd and ignores the rest, so v2 is backward compatible with the current Play page.
Softcode decides, the portal draws
Visibility, status words, name colours, actions, locks and hints all come from softcode (FN`WHOROW / FN`EXITROW). The client invents none of them.
Whole lists, not diffs
Send the full list on every change, as ROOM`CONTENTS does now. Idempotent and easy to recover after a reconnect.
Images by reference
URLs into the portal asset library with alt, width and height (no layout jump) and an optional focal point for cropping. Never inline image data.
Stable identity
Use objid alongside dbref so cached images and open sheets survive a recycled dbref.
Privacy by omission
Dark exits, hidden objects and idle times are left out by softcode, not hidden by the client.
