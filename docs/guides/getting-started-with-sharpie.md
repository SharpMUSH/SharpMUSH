# Getting started with Sharpie

Open `/welcome`, or choose **Getting started with Sharpie** from Help. The guide
is optional: **Let me figure it out myself** takes you directly to the game. You can return to
Help to choose another starting point or resume later.

Choose the experience closest to yours: Discord, MUSHes, another roleplay
environment, or independent exploration. Your game may supply its own welcome,
rules and character guide. Those explain its setting and community expectations.

The MUSH path is a four-step tour of what changes: web accounts, linking your
existing character, Story/Terminal views and this game's additions. It does not
require novice command practice. The common-command reference stays available.

## Accounts and characters

Your account signs you into the website. A character is the identity you play in
the world. Sign in, then create a character or claim an existing character using
its credentials. Games may restrict registration or character creation; follow
the game's instructions when an option is unavailable.

The guide offers to import progress started in this browser after you sign in.
Nothing is imported until you choose. Signed-in progress belongs to your account;
player and administrator checklists are separate.

## Your first commands

Practice in the guide is a local simulation. It does not contact other players.
The **look** insertion option fills an empty, connected terminal command box or
Story command composer. Review it and send it yourself. It never replaces an
existing draft. Story view is available when a scene is available; you can always
use the normal terminal to run commands.

| Command | Purpose | Who receives the output |
| --- | --- | --- |
| `look` | See the current room | You |
| `help` | Read built-in help | You |
| `help say` | Read help for a specific command | You |
| `inventory` | See what you carry | You |
| `who` | See connected players | You |
| `say Hello` | Speak in the room | People in the room |
| `pose waves.` | Describe your character's action | People in the room |
| `page NAME=Hello` | Send a private message | The named player |

Each game may provide additional commands. Consult its help; a package being
mentioned elsewhere does not prove that it is installed in your game.

Close or skip guidance whenever you prefer. Artwork preferences do not change
the written instructions. If progress changed in another tab, reload it before
making further choices.
