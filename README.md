# SharpMUSH help export

The general help as the game serves it, exported from SharpMUSH main by
`.github/workflows/help-export.yml`. Do not edit this branch: each export replaces it.

- `help/`: the engine's help files and every shipped plugin's, each under its own file name, with the
  plugin listings written into the index topics they belong on.
- `articles.json`: every article in them, with its id, lookup, title, aliases, sections, the file it is
  in, and the plugin it came from.
