Primary, smiling and minimal marks are refined native SVG reconstructions of the owner's chosen concepts. The circular badge derives directly from primary; the independently drawn rounded badge was rejected and removed. All use dark teal, mint and pure white. The design standard distinguishes measured geometry from recommended size and spacing rules. No application logos are replaced by this asset-only package.
