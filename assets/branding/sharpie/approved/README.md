# Sharpie approved mascot assets

[Open the design standard](sharpie-design-standard.html).

Three owner-selected designs: primary (sheet 1 option 1), smiling head (sheet 2 option 7), minimal sitting mascot (sheet 2 option 8), plus a circular badge derived directly from primary. The independently drawn rounded badge was rejected and removed.

The SVG masters and transparent PNGs use ink `#17333E`, mint `#00DDB3` and pure white `#FFFFFF`. The circular badge reuses primary geometry; the primary chin artifact is corrected and all contours are refined.

- `svg/`: editable path SVG masters
- `png/`: 1024 px transparent renders
- `sharpie-approved-preview.png`: light/dark comparison
- `provenance/`: reproducible reconstruction, measurements and hashes
- `sources/`: preserved approval sheets

The professional HTML standard includes roles, measured bounds, palette, clear space, minimum-size recommendations, immutable features, expression, motion, banners, accessibility and asset preflight. It is self-contained within this directory and uses local asset references.
