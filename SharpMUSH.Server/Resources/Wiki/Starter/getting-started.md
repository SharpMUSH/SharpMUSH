# Getting Started

## New to MUSHes?
A MUSH is a text game where you write your character's actions alongside other
players in real time. You don't need to know any code to play.

## Your first hour
1. Connect from the web terminal or a MU* client.
2. Create a character with `create <name> <password>`, then log in with
   `connect <name> <password>`.
3. Read the [[Theme]] and [[Policies]] pages.
4. Make your character.
   > **Fill in:** How character creation works here, and whether staff approve characters.
5. Say hello to other players.
   > **Fill in:** The channel newcomers can ask questions on.

## Commands you will use first
| Command | What it does |
|---|---|
| `look` | Describe the room you are in |
| `say <text>` | Speak in character |
| `pose <text>` | Act in character |
| `page <name>=<text>` | Send a private message |
| `help` | Open the full command reference |
