# playmem()

`playmem([<player>])`

The TinyMUX form of [playermem()]: *<player>* is optional and defaults to you. A player you cannot examine gives `#-1 PERMISSION DENIED`. SharpMUSH does not count memory per object, so the answer is 0.

This function comes from TinyMUX.
